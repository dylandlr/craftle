# Neural assisted-option layer v1

Select CRAFTLE_BEHAVIOR=learned_survival_options. A seven-feature structured observation (health, hunger, food availability, nearest hostile distance, inventory stacks, blocked status, horizontal displacement) drives a randomly initialized 7-16-4 tanh DQN. Actions are scripted assisted options eat/forage/explore/retreat, not primitive motor actions. Forage includes programmed food knowledge; no claim of discovering those skills is permitted. No LLM or pretrained Minecraft weights are used.

One decision per reference loop interval (default 1800ms). Online TD learning uses real transition replay (512 maximum), four replay updates per observed transition, a separate target network refreshed every 100 gradient updates, epsilon .3, gamma .95, alpha .002 and clipped TD error. These are prototype defaults, not tuned optima. Rewards: fresh horizontal spatial cell +.2, health loss .5 per point, hunger gain .05 per point, inventory stack increase .1 per stack, step cost -.02, terminal death -5 without respawn bootstrapping. These proxies can be exploited and must be evaluated independently. Eat is masked only if inventory lacks food. There is no scripted survival override of the policy. Death remains possible.

The policy/checkpoint persists across respawns; checkpoint stores network weights and update count, not replay contents. Replay and visitation memory are session-local. Shutdown truncates the final pending transition; it does not fabricate a terminal death. Original visual-Q/reward-v1 and scripted reference remain available.

The first experiment is a short infrastructure pilot with real POV, decisions, rewards and checkpoint artifacts. It cannot establish emergent intelligence or superiority. Next: matched-budget scripted/random-option/frozen-neural controls and multiple training/evaluation seeds, then explicit options for social interaction, communication and resource exchange. Multi-agent learning, sleep consolidation, self-discovered skills and technology discovery are not implemented by this change.

This milestone establishes an operational neural decision layer over assisted scripted options. It does not establish intelligent skill discovery, improved survival, technology discovery, or social emergence. The forage macro still supplies food-search/harvest/combat knowledge; options are not primitive motor controls. The next controlled experiment needs scripted, random-option, frozen-neural and training-neural treatments with identical sensor/action contracts and budgets. Add social state and communication/transfer actions only as explicit schema-version changes with their own multi-agent evaluation.
